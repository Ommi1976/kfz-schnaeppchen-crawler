# KFZ Schnäppchen Crawler

Findet Gebrauchtwagen-**Schnäppchen** über AutoScout24, Kleinanzeigen,
AutoUncle, mobile.de und heycar und meldet neue Treffer an Home Assistant.

Aus allen Treffern einer Suche wird ein **Marktpreis (Median)** berechnet;
Inserate deutlich darunter werden als Schnäppchen gemeldet – jedes nur einmal.
